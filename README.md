# Swasthai

AI-powered patient triage and clinic queue management.

## Overview

Swasthai helps clinics prioritize patients based on structured intake information, improving workflow and reducing waiting time.

## Features

- Patient intake
- Risk categorization
- Queue management
- Doctor dashboard
- Real-time updates

## Tech Stack

- Next.js
- TypeScript
- Supabase
- Tailwind CSS
