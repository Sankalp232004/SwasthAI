# SwasthAI WhatsApp Message Library & Copywriting Playbook

This library contains the master templates, specialty variations, bilingual Hinglish options, multi-stage follow-up sequences, and objection response scripts used in SwasthAI's WhatsApp outreach engine.

All copy is written in **natural Indian professional English**, strictly maintains doctor autonomy, and focuses 100% on clinic operations (zero medical diagnosis claims, zero corporate jargon, zero exaggerated statistics).
